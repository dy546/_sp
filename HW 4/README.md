# HW 4 - System Programming Guide (Static Website)

A comprehensive guide to system programming concepts, built as a static website with dark mode support.

## Features

- Dark/light mode toggle with localStorage persistence
- 8 chapters covering: OS overview, assembly, compilers, kernel, linkers, tools, security, and advanced topics
- Responsive card-based layout

## Tech Stack

- HTML, CSS, JavaScript (no build step)

## Quick Start

Open `index.html` in your browser, or run:

```bash
./start.sh
```
